# ICE40 FPGA

This folder contains the files I used while learning and testing the ICE40 FPGA blinking project.

## Contents
- `blink.v` – Verilog code for blinking an LED.
- `Makefile.txt` – Used to build the project and generate the bitstream.
- `blink.pdf` – Reference document for the project.

## Purpose
The main goal of this project was to understand the basic FPGA workflow, from writing Verilog code to generating the bitstream(in four stages)and finally flashing it onto the ICE40 FPGA.
